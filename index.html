See the work. Keep it yours.

A personal kanban board that lives in a folder on your machine — for projects, plans, and everything you’re juggling. No account. No cloud workspace.

One person. A lot of moving pieces.

Dodalu is built for solo work — the stuff that falls apart in a shared team board, or never belonged there in the first place.

Ship a project without losing the thread

Side apps, client work, weekend builds — columns for what’s next, what’s stuck, and what’s done.

Keep life goals off the guilt spreadsheet

Fitness, finances, learning — a board you actually look at, not a list that grows forever in a notes app.

Plan the messy middle

Trips, moves, renovations, launch weeks — stages you invent for the real sequence, not a generic “todo / doing / done.”

Run a personal pipeline

Writing, courses, content, job applications — each piece is a card you can move as it progresses.

Open a folder. Get a board.

Point Dodalu at any folder. You get columns and cards on this machine — nothing to sign up for, nothing syncing to someone else’s servers unless you choose to.

01

Shape the board

Columns, colors, wallpaper, tags, and buckets — tuned to this project, not a workspace template.

02

Write real notes

Every card can open a Markdown document beside the board — checklists, research, specs, packing lists.

03

Stay in control

Search, tag filters, archive, undo. Live board state stays on your machine; durable notes can live with the project.

Cards that hold more than a title.

Select a card and its Markdown opens in the same window — preview by default, edit when you need it, or jump to your usual editor.

Building with agents? Give them a board too.

If you already work in Cursor, Claude Desktop, Codex, or Copilot, optional MCP lets those tools create and move cards on your board — while Dodalu stays a calm place to see the whole picture. Conversations stay in your editor; the board stays yours.

Register agent clients from the app when you want them. Skip it entirely if you just want a quiet personal board.
