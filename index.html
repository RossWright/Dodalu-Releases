Features

Dodalu is a local-first desktop kanban app for a single user. Here is what it does today:

  • Personal kanban boards that run on Windows and Linux (desktop app)
  • No account and no required cloud sync — board data stays on your computer
  • Boards catalog on the welcome screen with recent projects and sorting
  • New Board wizard: location, name, structure, look, and settings
  • Quick boards stored on this computer, or boards inside a new or existing project folder
  • Import a board from a Trello JSON export (lists, cards, labels, checklists)
  • Custom stages (columns) with colors, widths, collapse, and reorder in edit mode
  • Built-in themes, board wallpaper, and card/selection/bucket colors
  • Cards with titles, summaries, colored tags, and optional Markdown backing documents
  • In-app Markdown preview and source editor, with open-in-external-editor
  • Buckets to group related cards one level deep inside a stage
  • Search across titles and summaries, with optional search in Spec documents
  • Tag filters on the board; manage a project tag catalog
  • Archive and restore cards (optional permanent delete)
  • Undo and redo for board content changes
  • Cut, copy, paste, and copy-to between boards; drag cards across Dodalu windows
  • Optional effort tracking with estimates and work entries
  • Optional MCP server so external agents (Cursor, Claude Desktop, Codex, Copilot) can create, update, and move cards
  • Board state as local JSON plus Markdown files you can keep with a project
  • In-app updates from the Dodalu release feed; optional paid license via Lemon Squeezy
